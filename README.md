# Mellow Coffee — сайт-визитка

Одностраничный сайт кофейни на Next.js (App Router, TypeScript, Tailwind CSS,
Framer Motion, Zustand), архитектура — Feature Sliced Design.

## Структура проекта

```
src/
  app/            — точка входа Next.js (layout, page, globals.css)
  shared/         — переиспользуемые UI-компоненты, конфиг, хуки, валидаторы
  entities/       — бизнес-сущности (пункт меню)
  features/       — фича «форма бронирования» (стор, валидация, API-вызов)
  widgets/        — секции лендинга (Header, Hero, Menu, About, Space, Visit, Booking, Footer)
cloudflare-worker/ — воркер, пересылающий заявки в Telegram
```

## 1. Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000 — сайт с горячей перезагрузкой.

## 2. Настройка Telegram-бота (Cloudflare Worker)

1. Создайте бота через **@BotFather** в Telegram → команда `/newbot` → получите
   `TELEGRAM_BOT_TOKEN`.
2. Узнайте `chat_id`: добавьте бота в нужный чат/группу и отправьте туда любое
   сообщение, затем откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — id чата будет в ответе
   (поле `chat.id`).
3. Установите Wrangler и авторизуйтесь:
   ```bash
   npm install -g wrangler
   wrangler login
   ```
4. Из папки `cloudflare-worker/` задеплойте воркер и задайте секреты:
   ```bash
   cd cloudflare-worker
   wrangler deploy
   wrangler secret put TELEGRAM_BOT_TOKEN
   wrangler secret put TELEGRAM_CHAT_ID
   ```
5. Скопируйте URL задеплоенного воркера (вида
   `https://mellow-coffee-booking.<аккаунт>.workers.dev`) и вставьте его в
   `src/shared/config/site.ts` → `bookingWorkerUrl`.
6. В `cloudflare-worker/worker.js` замените `ALLOWED_ORIGIN = '*'` на реальный
   домен вашего сайта, чтобы форму нельзя было дёргать с чужих доменов.

Токен и chat_id никогда не попадают во фронтенд-код — они живут только в
секретах воркера.

## 3. Сборка и деплой сайта

Сайт настроен на статический экспорт (`output: 'export'` в `next.config.js`) —
получится папка `out/`, которую можно захостить где угодно.

```bash
npm run build
```

### Вариант A — Netlify
1. Залейте репозиторий на GitHub.
2. В Netlify: **Add new site → Import from Git**.
3. Build command: `npm run build`, Publish directory: `out`.

### Вариант B — GitHub Pages
1. В `next.config.js` раскомментируйте `basePath`/`assetPrefix` и подставьте
   имя репозитория.
2. `npm run build` → получите папку `out/`.
3. Запушьте содержимое `out/` в ветку `gh-pages` (вручную или через Action
   `peaceiris/actions-gh-pages`).
4. Включите GitHub Pages для ветки `gh-pages` в настройках репозитория.

## 4. Замена изображений

В `Hero`, `AboutSection` и `SpaceSection` сейчас стоят цветные плейсблоки
(`bg-terracotta/20 grain` и т.п.) вместо фото — так референс не подменяется
случайными стоковыми картинками. Замените эти `div` на `<Image />` из
`next/image` с вашими реальными фотографиями интерьера и напитков.

## Самоанализ (этап 3.4)

**Соответствие референсу.** Сохранены: гигантская display-типографика на всю
ширину экрана, чередование цветных секций-блоков (крем / шалфей / мёд /
эспрессо) вместо градиентов, pill-кнопки с hover-bounce, бегущая строка
(marquee) как декоративный разделитель, плавающий круглый бейдж-маскот.
Палитра сознательно смягчена под характер кофейни («мягкий свет, без
спешки») — вместо кислотного розового и оранжевого использованы кремовые,
терракотовые и шалфейные тона.

**Wow-эффект.** Достигается за счёт: scroll-reveal анимаций секций (Framer
Motion `whileInView`), параллакса в секции «Пространство», микроанимаций на
кнопках и карточках меню (hover/tap с пружинной физикой), бегущей строки и
плавающего бейджа. Всё это — по одному приёму на слой, без нагромождения.

**Перегруз.** Не выявлен: на каждую секцию — один смысловой блок и один-два
визуальных акцента; фото-плейсхолдеры простые, без лишней декоративщины.

**Ограничения, о которых стоит знать:**
- Реальные фотографии интерьера/напитков не подставлены (см. п.4) — сейчас
  это цветные плейсхолдеры, повторяющие пропорции референсных коллажей.
- Проект не был собран и не запущен в этой среде (нет доступа к npm-registry
  в песочнице), поэтому перед продакшен-деплоем обязательно выполните
  `npm install && npm run build` локально и проверьте вывод на ошибки типов.
- Встроенная карта в секции «Визит» — плейсхолдер; вставьте туда iframe
  Яндекс.Карт или Google Maps с вашим адресом.
